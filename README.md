# kivy-Learning 🚀

A small, friendly collection of Kivy examples to help you learn the framework with practical, focused scripts.

Why this repo? 🎯

- Short, self-contained examples that demonstrate common Kivy patterns.
- Great for beginners who want runnable snippets and quick experimentation.

Highlights ✨

- Clear, minimal examples for UI building, layout, widgets, and simple interactions.
- Files are independent — run any example directly.

Key files 📁

- `calculator.py` — simple calculator example.
- `calculator_no_eval.py` — safer calculator implementation without `eval`.
- `calculator_one_loop.py` — a compact calculator logic with a single loop.
- `hello_world.py` — quick Kivy hello world to get started.
- `label_button_text.py` — working with `Label`, `Button`, and text input.
- `letters_textbox.py` — text-box handling and character input.
- `multiplication_grid.py` — displays a multiplication grid.
- `grid_3x5.py` — layout example: a 3×5 grid.
- `popup_simple.py` / `popup_advanced.py` — simple and advanced popup examples.
- `toggle_gender.py` — toggle/switch control example.
- `chess_board.py` — visual demonstration for creating a chessboard layout.

Requirements ⚙️
You only need Python and Kivy. Using a virtual environment is recommended.

Installation (Windows) 🧩

```powershell
python -m venv .venv
.\venv\Scripts\Activate.ps1
pip install --upgrade pip
pip install kivy
```

If you have `requirements.txt`:

```powershell
pip install -r requirements.txt
```

Run an example ▶️

```powershell
python hello_world.py
# or any other file, e.g.:
python calculator.py
```

Tips & Notes 📝

- If you hit installation issues on Windows, check the official Kivy installation guide: https://kivy.org
- Run examples from this repository root so relative assets (if any) resolve correctly.
